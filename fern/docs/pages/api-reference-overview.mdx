## 当前范围 / Current scope

REST、AQL、包客户端协议、JFrog CLI 与 CI 集成均属于最终范围；当前没有已通过全功能兼容验收的 BinFlow API。
The final scope includes REST/AQL, package protocols, JFrog CLI and CI integrations. No BinFlow API currently has full-parity acceptance.

首个工程任务 [BIN-123](https://linear.app/binfloow/issue/BIN-123) 建立内部健康检查 `/healthz` 的 GET/HEAD 与方法拒绝契约。它用于研发 smoke，不属于 Artifactory API 兼容证明。
The first engineering task defines internal health/method contracts for smoke checks; it is not an Artifactory compatibility assertion.

## 后续参考生成 / Future reference generation

Freeze baseline behavior/errors/authorization before writing original specifications and contracts. Publish support only after implementation and verification.
