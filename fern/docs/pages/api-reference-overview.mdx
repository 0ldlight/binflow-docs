目前尚无已发布并验证的 BinFlow 产品 API，因此暂不提供调用示例或兼容性保证。
No verified BinFlow product API has been released, so request examples and compatibility guarantees are not available yet.

已支持接口的请求、响应、认证方式、错误及版本限制将在相应版本发布后补充。
Request/response formats, authentication, errors and version limits will be documented with supported releases.
