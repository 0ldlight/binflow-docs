源码构建的受限预览提供普通 GET/HEAD 下载和 PUT 上传；认证、调用示例、权限与错误处理见[配置下载与上传](/configure-downloads)。
The limited source-build preview supports ordinary GET/HEAD downloads and PUT uploads. See [Configure downloads and uploads](/configure-downloads) for authentication, request examples, permissions and errors.

目前尚无正式产品 API 发行版或完整兼容性保证。正式版本的接口与版本限制将在相应发行版中提供。
A formal product API release and full compatibility guarantee remain unavailable. Supported product interfaces and version limits will be documented with their releases.
